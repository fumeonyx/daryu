# Дарю — подбор подарков

React + Vite проект для подбора подарков. Есть анкета, карточки подарков, избранное, ссылки "В магазин", добавление своих подарков и общая база через Supabase.

## Запуск

```bash
npm install
npm run dev
```

Открой адрес из терминала, обычно `http://localhost:5173/`.

## Supabase: чтобы подарки видели другие люди

1. Зайди на https://supabase.com и создай новый проект.
2. Открой **SQL Editor**.
3. Скопируй содержимое файла `supabase.sql` и нажми **Run**.
4. Открой **Authentication → Sign In / Providers** и включи **Anonymous sign-ins**.
5. Открой **Project Settings → API**.
6. Скопируй:
   - Project URL
   - anon public key
7. В проекте скопируй `.env.example` в `.env`.
8. Вставь значения:

```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-public-key
```

9. Перезапусти проект:

```bash
npm run dev
```

Если всё подключилось, в форме добавления будет статус: **Общая база Supabase включена**.

## Публикация сайта

Самый простой вариант — Vercel или Netlify.

При публикации не забудь добавить переменные окружения:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

## MVP

- анкета: кому, повод, бюджет, характер, интересы;
- алгоритм подбора подарков по совпадениям;
- карточки подарков с ценой, тегами и причиной;
- избранное в браузере;
- шаринг подборки ссылкой;
- кнопки "В магазин";
- добавление подарков в общую базу Supabase;
- удаление только своих добавленных подарков;
- адаптивный дизайн.
